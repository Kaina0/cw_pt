# cw_pt

何枚もの測定結果帳票(Excel)を1つの集約帳票にまとめるプログラムです。

`samples/` に置かれた測定結果ファイル(1ファイル1サンプル)をすべて読み込み、
規格値との合否判定を行った上で、1つの一覧表(`output/aggregate_report.xlsx`)に
集約します。

## Before / After

**Before: サンプルごとに1ファイル(帳票)がバラバラに存在する**

```
samples/
├── sample_01_A0001.xlsx    測定日: 2026/08/10  測定者: 佐藤  製品番号: A0001
├── sample_02_A0002.xlsx    測定日: 2026/08/10  測定者: 鈴木  製品番号: A0002
├── sample_03_A0003.xlsx    測定日: 2026/08/11  測定者: 高橋  製品番号: A0003
├── sample_04_A0004.xlsx    測定日: 2026/08/11  測定者: 田中  製品番号: A0004
└── sample_05_A0005.xlsx    測定日: 2026/08/12  測定者: 伊藤  製品番号: A0005
```

各ファイルは以下のような単票フォーマット(sample.xlsx と同じレイアウト)です。

```
 測定日   2026/08/10    測定者   佐藤

 製品番号 A0001

 寸法測定値  149.0
 寸法規格値  150±5
 重量測定値  1003.0
 重量規格値  1000±20
```

**After: 1つの集約帳票にまとめ、規格判定まで付与**

```
| ファイル名               | 測定日     | 測定者 | 製品番号 | 寸法測定値 | 寸法規格値 | 寸法判定 | 重量測定値 | 重量規格値 | 重量判定 | 総合判定 |
|---------------------------|------------|--------|----------|------------|------------|----------|------------|------------|----------|----------|
| sample_01_A0001.xlsx       | 2026/08/10 | 佐藤   | A0001    | 149.0      | 150±5      | 合格     | 1003.0     | 1000±20    | 合格     | 合格     |
| sample_02_A0002.xlsx       | 2026/08/10 | 鈴木   | A0002    | 151.2      | 150±5      | 合格     | 995.0      | 1000±20    | 合格     | 合格     |
| sample_03_A0003.xlsx       | 2026/08/11 | 高橋   | A0003    | 158.0      | 150±5      | 不合格   | 1010.0     | 1000±20    | 合格     | 不合格   |
| sample_04_A0004.xlsx       | 2026/08/11 | 田中   | A0004    | 147.5      | 150±5      | 合格     | 1024.0     | 1000±20    | 不合格   | 不合格   |
| sample_05_A0005.xlsx       | 2026/08/12 | 伊藤   | A0005    | 150.0      | 150±5      | 合格     | 1000.0     | 1000±20    | 合格     | 合格     |
```

規格外の値には赤色のハイライトが付き、ひと目で不合格サンプルを確認できます。

## セットアップ

```bash
pip install -r requirements.txt
```

## 使い方

```bash
# 1. sample.xlsx をテンプレートにサンプル帳票を5件生成(samples/ に出力)
python3 generate_samples.py

# 2. samples/ 配下の帳票を1つの集約帳票にまとめる(output/aggregate_report.xlsx に出力)
python3 aggregate_report.py
```

集約対象のディレクトリや出力先を変えたい場合は引数で指定できます。

```bash
python3 aggregate_report.py <samples_dir> <output_path>
```

## ファイル構成

| ファイル | 役割 |
|---|---|
| `sample.xlsx` | 測定結果帳票のテンプレート(単票フォーマット) |
| `generate_samples.py` | `sample.xlsx` を元にサンプル帳票を複数生成するスクリプト |
| `aggregate_report.py` | 複数の帳票を読み込み、1つの集約帳票にまとめるスクリプト |
| `samples/` | 生成された(または実測定で作成された)個別帳票の格納先 |
| `output/` | 集約帳票の出力先 |

## 帳票のセルレイアウト(固定)

`aggregate_report.py` は各帳票の以下のセル位置を前提に読み取ります。

| セル | 項目 |
|---|---|
| C3 | 測定日 |
| E3 | 測定者 |
| C6 | 製品番号 |
| C11 | 寸法測定値 |
| C12 | 寸法規格値(例: `150±5`) |
| C13 | 重量測定値 |
| C14 | 重量規格値(例: `1000±20`) |

規格値は `公称値±許容差` の形式をパースし、測定値がその範囲内かどうかで
合否判定(合格 / 不合格)を行います。
